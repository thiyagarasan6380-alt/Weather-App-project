🌦️ Weather App

A simple and responsive Weather Application built using HTML, CSS, and JavaScript that provides real time weather information for any city using a weather API.

🚀 Features

- 🔍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Show weather condition
- 💧 Display humidity
- 🌬️ Show wind speed
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and easy to use interface

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Weather API

⚙️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Search for a city to view its weather information.
